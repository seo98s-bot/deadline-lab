# 데드라인 랩 — 업무 기한 계산기

**바이브코딩 웹앱 과제 제출용 정적 웹사이트**입니다. HTML/CSS/JavaScript를 `index.html` 하나에 담았으며 별도 설치·유료 API·데이터베이스 없이 작동합니다.

## 주요 기능

- 시작일, 기간(일), 업무명 입력
- 달력 기준 / 주말 제외 근무일 기준 마감일 동시 계산
- 시작일 포함 여부 선택
- 휴무일을 직접 입력해 근무일 계산에 반영
- 오늘 기준 D-day, 달력에서 마감일 비교
- 계산 결과 복사
- 최근 20개 계산 이력을 브라우저에 저장·불러오기·삭제
- 스마트폰·태블릿·PC 반응형 지원

## 사용 방법

`index.html` 파일을 브라우저에서 열면 됩니다.

계산 원칙: 기본 설정은 **시작일 제외**(다음 날부터 1일째)입니다. 근무일은 월~금요일이며 사용자 입력 휴무일은 제외됩니다. **국가별 공휴일은 자동 반영되지 않습니다.** 기간 0일은 시작일을 반환합니다.

> 이 서비스는 일반적인 일정 관리 도구입니다. 실제 법정 기한(초일 산입·휴일 연장·기간 계산 특례 등)은 관련 법령을 확인해 별도로 판단해야 합니다.

## GitHub에 올리는 방법

1. GitHub 로그인 → **New repository** → 저장소 이름 `deadline-lab` → **Public** → **Create repository**.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더의 `index.html`, `README.md` 파일을 업로드합니다.
3. **Commit changes**를 눌러 저장합니다.

## Vercel 배포

1. [Vercel](https://vercel.com/) 로그인 → **Add New → Project**.
2. GitHub를 연결하고 방금 만든 `deadline-lab` 저장소를 가져옵니다.
3. **Framework Preset**은 `Other`, **Root Directory**는 `./` 그대로 두고 **Deploy**.
4. 생성된 `https://...vercel.app` URL에 접속해 앱을 확인합니다.
5. 위 URL을 과제 제출란에 입력합니다. (개인 Vercel 설정에 따라 배포 메뉴 명칭은 달라질 수 있습니다.)

## 기술 및 개인정보

기술: 순수 HTML5, CSS3, Vanilla JavaScript. 외부 라이브러리·외부 이미지·서버 전송 없음. 저장 기록은 사용자 브라우저 `localStorage`에만 보관됩니다.

## 테스트 체크리스트

- [ ] 기간 14일 계산 시 두 마감일이 함께 표시된다.
- [ ] 근무일 계산에서 토요일·일요일이 제외된다.
- [ ] 휴무일을 입력하면 근무일 마감일이 필요에 따라 바뀐다.
- [ ] 시작일 포함을 체크하면 결과가 바뀐다.
- [ ] D-day, 결과 복사, 이력 저장·불러오기가 된다.
- [ ] 스마트폰 화면에서 가로 스크롤 없이 동작한다.
